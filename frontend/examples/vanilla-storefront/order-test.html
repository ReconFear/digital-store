Тестовая страница: POST /orders

Только для разработчиков и только с тестовой базой.

Кнопка создаёт настоящую запись заказа в той базе, к которой подключён backend (по умолчанию из .env — основная digital_store!). Заказ получает статус pending. Оплаты нет, товар не резервируется и не выдаётся — это проверка связи frontend ↔ backend, а не покупка.

Перед проверкой запустите backend на тестовой базе: $env:DB_NAME = "digital_store_test".
