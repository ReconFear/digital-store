# Digital Store — API для фронтенда

## Адрес backend

При локальной разработке:

`http://127.0.0.1:8000`

## 1. Получить все товары

**GET** `/products`

Ответ:

```json
{
  "products": [
    {
      "id": 1,
      "name": "Minecraft Key",
      "price": 999,
      "quantity": 14,
      "is_for_sale": true
    }
  ],
  "total": 1
}
```

Это пример формата ответа. Настоящий список и остатки могут отличаться.

## 2. Получить только доступные товары

**GET** `/products?available_only=true`

Возвращает товары, которые разрешено продавать и у которых остаток больше нуля.

## 3. Получить товар по ID

**GET** `/products/1`

Возвращает информацию об одном товаре.

Если товара нет — ошибка `404`.

## 4. Создать заказ

**POST** `/orders`

Тело запроса:

```json
{
  "product_id": 1
}
```

Успешный ответ — `200 OK`:

```json
{
  "message": "Order created",
  "order": {
    "id": 1,
    "product_id": 1,
    "price": 999
  }
}
```

Ошибки:

- `404` — товар не найден.
- `409` — товар недоступен для покупки.
- `422` — неверный формат запроса.

## 5. Получить список заказов

**GET** `/orders`

Возвращает объект с полями `orders` и `total`.

## Важно

- Все данные передаются в формате JSON.
- Оформление покупки учебное, без настоящей оплаты.
- Backend пока запускается локально.
- Если frontend работает на другом компьютере, адрес `127.0.0.1` не приведёт к нашему backend: для совместной работы потребуется доступный адрес сервера.
